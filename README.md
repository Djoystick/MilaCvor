## 🚀 Быстрый запуск на локальном компьютере

1. **Установка зависимостей:**
   ```bash
   npm install
   ```

2. **Запуск локального сервера:**
   ```bash
   npm start
   ```

3. Откройте в браузере: `http://localhost:3000`

## 🎛️ Панель управления (CMS)

Сайт оснащен полнофункциональной панелью администратора без необходимости редактировать код:

1. Перейдите по ссылке `https://цвор.рф/#admin` (или нажмите `Ctrl+Shift+A` / кликните по символу `©` в подвале сайта).
2. Введите пароль администратора: **`mila2026`**
3. В панели доступны 5 разделов:
   * **Тарифы и цены** — изменение стоимости пакетов, опций и продления.
   * **Галерея и VK** — загрузка новых фотографий и импорт из фотоальбомов группы ВК.
   * **Главная & Обо мне** — редактирование заголовков, текстов и портретного фото.
   * **Отзывы & FAQ** — управление отзывами клиентов и блоком вопрос-ответ.
   * **Контакты & Сети** — номера телефонов, ссылки и график работы.
