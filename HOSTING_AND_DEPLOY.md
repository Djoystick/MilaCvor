## 🔄 3. Как новому владельцу получить доступ к хостингу

### Вариант 1: Делегирование прав в существующем каталоге Yandex Cloud (Самый простой)
Если сайт остается на текущем облачном сервере:
1. Текущий администратор заходит в консоль: [console.cloud.yandex.ru](https://console.cloud.yandex.ru).
2. Переходит в Каталог (`b1ga1ne6grob01bo1vaj`) ➔ вкладка **«Права доступа»** ➔ кнопка **«Назначить роли»**.
3. Вводит Яндекс-логин нового владельца (или программиста) и назначает роль **`editor`** или **`admin`**.
4. Новый владелец сможет самостоятельно управлять функцией, шлюзом, сертификатом и загружать новые версии.

---

### Вариант 2: Перенос на собственный аккаунт Яндекс Облака нового владельца
Если новый владелец хочет иметь сайт полностью на собственном отдельном договоре Yandex Cloud:
1. Зарегистрироваться в [Yandex Cloud](https://cloud.yandex.ru) и создать новый каталог.
2. **Создать сервисный аккаунт:**
   * Имя: `tsvor-invoker`, роль: `serverless.functions.invoker`.
3. **Создать функцию Cloud Functions:**
   * Имя: `tsvor-api`, среда выполнения: **Node.js 22**.
   * Точка входа: `handler.handler`, память: `256 МБ`, таймаут: `10s`.
   * Загрузить содержимое этой папки в виде ZIP-архива.
4. **Создать API Gateway:**
   * Открыть файл `yandex-api-gateway.yaml` из этой папки.
   * Заменить `function_id` и `service_account_id` на ID созданных на шагах 2-3 ресурсов.
   * Вставить спецификацию в форму шлюза и нажать «Создать».
5. **Привязать домен:**
   * В сервисе **Certificate Manager** заказать бесплатный сертификат Let's Encrypt на домен `цвор.рф` (Punycode: `xn--b1aygv.xn--p1ai`).
   * В настройках API Gateway добавить привязку домена с созданным сертификатом.
   * В DNS-записях домена направить CNAME/A-запись на адрес шлюза.

### Вариант 3: Запуск на классическом хостинге / VPS / Vercel
Проект спроектирован по модульным стандартам и не привязан намертво к одному провайдеру:
* **На любом сервере или VPS (Ubuntu/Debian):**
  ```bash
  npm install
  node server.js
  # или через процесс-менеджер:
  pm2 start server.js --name "mila-site"
  ```
* **На хостинге Vercel:**
  В корне проекта уже находится готовый файл `vercel.json` — достаточно подключить репозиторий и нажать Deploy.
