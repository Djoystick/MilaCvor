   - **Переключатель:** Бесшовный тоггл темы в шапке (Sun/Moon) с сохранением состояния в `localStorage` и Zero-Flash гидратацией.

### Фирменные WOW-эффекты и интерактив (v1.3.0 Architecture):
1. **Двухслойная архитектура холстов (Dual-Canvas Architecture):**
   - **Фоновый холст (`#fairy-particles`, `z-index: 1`):** Обеспечивает глубокое фоновое парение светлячков и сказочной мерцающей пыльцы за полупрозрачными панелями сайта.
   - **Передний интерактивный холст (`#fairy-magic-canvas`, `z-index: 99999; pointer-events: none`):** Вынесен поверх всех DOM-слоев, карточек, заголовков и фотографий. Гарантирует 100% видимость волшебных шлейфов, вспышек и мобильных искр без блокировки кликов и взаимодействия с интерфейсом.
2. **«Волшебная палочка Фотофеи» (Fairy Wand Starlight Cursor Trail — Десктоп):**
   - При движении мыши за курсором стелется светящийся шлейф из вращающихся 4-конечных звезд (`✦`), микро-искр и золотисто-розовой пыльцы с физикой затухания и гравитации (60 FPS Canvas).
3. **«Вспышка сказочной камеры» (Fairy Camera Shutter Flash — Десктоп и Мобильные):**
   - При клике мыши или тапе по экрану происходит трехфазная анимация:
     1. Мгновенный мягкий радиальный засвет объектива (Lens Bloom Exposure) с градиентом от белого центра к теплому золотому ореолу.
     2. Быстро расширяющееся кольцо затвора диафрагмы фотокамеры (Shutter Ring).
     3. Взрыв из 12-16 радиально разлетающихся звездных искр (Starburst Sparks).
4. **Фирменный мобильный эффект «Волшебное прикосновение Фотофеи» (Magic Fairy Touch):**
   - **След при скролле (`touchmove`):** При ведении пальцем по экрану из-под пальца вылетают деликатные золотые и розовые искры, создавая тактильное ощущение рисования светом при чтении сайта.
   - **Вспышка при касании (`touchstart`):** Моментальный расцвет вспышки объектива прямо под местом прикосновения.
   - **Тактильный отклик (Haptic Feedback):** При каждом тапе срабатывает микро-вибрация `navigator.vibrate(10)`, имитирующая тактильный щелчок фотокамеры на мобильных устройствах.
5. **Люксовый верхний индикатор скролла (`#scroll-progress`):**
   - Ультратонкий градиентный бар высотой 3px с мерцающим огоньком на конце (`z-index: 100000`), точно отражающий прогресс прокрутки страницы.
6. **Живые счетчики доверия (CountUp):**
   - Числа в ключевых метриках (100%, 15+, 48 ч, 5.0) плавно нарастают от 0 при появлении во viewport благодаря `IntersectionObserver` и кубической функции плавности.
7. **Атмосферное дыхание света (Breathing Fairy Glow `.fairy-glow-pulse`):**
   - Мягкая циклическая пульсация ореола вокруг спецпредложений и ключевых карточек.
8. **Плавающий мобильный конверсионный бар (`#mobile-sticky-bar`):**
   - Нижняя панель для смартфонов (`md:hidden`) с поддержкой `env(safe-area-inset-bottom)`.
   - Включает моментальный переход в чат сообщества VK с предзаполненным заказом/вопросом, прямой звонок фотографу и быструю запись.
   - Плавно активируется при скролле вниз (>260px) и скрывается на первом экране Hero.
9. **3D Tilt Perspective на карточках:**
   - Плавный объемный наклон карточек за курсором мыши на десктопе (`perspective(800px) rotateX/Y`).
10. **Shimmer Text Gradient (`.text-shimmer-gold`):**
    - Плавный бегущий золотисто-розовый блик на ключевых заголовках.

### 16. Устранение ошибки VK API 27: Поддержка ключей доступа сообщества [v1.7.2]
- **Проблема с методом `photos.get`:**
  - В архитектуре VK API метод `photos.get` строго запрещен при авторизации через Ключ доступа сообщества (код ошибки 27: `Group authorization failed: method is unavailable with group auth`).
  - При создании токена в группе (Управление -> Работа с API) генерируется именно ключ сообщества.
- **Двухфазный отказоустойчивый алгоритм:**
  - При отсутствии специфического альбома или при ошибке 27 сервер автоматически опрашивает `wall.get` по ID группы `-240592099` с фильтром `owner`.
  - Алгоритм извлекает фотографии из вложений `attachments.type === 'photo'`, выбирая максимальный размер из доступных (`w`, `z`, `y`, `x`), подтягивает описания постов и даты публикации.
  - Если запрашивался отдельный закрытый альбом, система отдает фото со стены и возвращает дружелюбное уведомление о необходимости сервисного ключа для приватных альбомов.
