# 🧠 Память проекта: Сайт-портфолио фотографа (Production Web Craft)

> Центральное хранилище архитектурных решений, концепций и бэклога проекта.

### 📌 Основной контекст проекта
* **Стек:** Чистый семантический HTML5, Tailwind CSS, Vanilla JS, Lucide Icons, GSAP + ScrollTrigger, Swiper.js
* **Деплой:** Vercel (Edge Network, Static CDN, 100/100 Lighthouse, Zero-CLS)
* **Архитектурный стиль:** Швейцарский минимализм, журнальная премиум-эстетика (vibeprompts.dev / Editorial)
* **Интеграция:** Группа ВКонтакте (отзывы, портфолио, контакты)

### 🛡️ Регламенты разработки (Global Rules)
1. **Правило сборки:** После каждого изменения в коде запускать синтаксическую валидацию (`node -c`).
2. **Правило релиза (Workflow):** ПЕРЕД СБОРКОЙ АКТУАЛИЗИРОВАТЬ ВЕРСИЮ И ЗАПОЛНЯТЬ ЧЕЙНЖЛОГ.
3. **Правило бекапов (Локальное):** Перед изменением любого файла ВСЕГДА делать его копию (`.bak_...`).
4. **Правило документации нововведений (Архитектурное):** Фиксировать архитектуру в `PROJECT_MEMORY.md`.
5. **Правило батчинга микро-изменений:** Мелкие правки тестируются локально и релизятся единым батчем.
